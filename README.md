# Portfólio

Página pessoal com os projetos e um console interativo de verdade (digite comandos como `ajuda`, `sobre`, `abrir lista-de-tarefas`).

**Demo ao vivo:** https://takkedaz.github.io/portfolio/

## Funcionalidades

- Console interativo com comandos reais (não é só visual)
- Links para os projetos, GitHub, LinkedIn e e-mail

## Tecnologias

- HTML5 / CSS3 / JavaScript (Vanilla JS)

## Como rodar localmente

Basta abrir o arquivo `index.html` em qualquer navegador.
